# Illustration System — تصویرسازی (The Paper-Cut Family)

The codified art system: one motif family, two sign systems, theme-paired
assets, zero runtime recoloring. Companion: `docs/brand-meraj.md`,
`docs/tone-of-voice.md`.

---

## 1. The family tree

All brand art derives from The Mark's proportion family
(`docs/brand-the-mark.md`): **line-only ~30° isometric, ink strokes, exactly
one gold element per motif**. Nothing else is drawn.

| Asset family | Component | Location | Use |
|---|---|---|---|
| Empty-state illustrations | `EmptyStateArt.tsx` | `/empty-art/{light,dark}/01–06` | Page-level absence moments (160px) |
| Absence art | `AbsenceArt.tsx` | `/empty-art/absence/{light,dark}/` | 404/missing pages |
| Hero art | (Login/marketing) | `/empty-art/hero/{light,dark}/` | Marketing surfaces only |
| Neutral art | — | `/empty-art/neutral/{light,dark}/` | Non-themed slots |
| Cuts (chrome icons) | `Cut.tsx` | `/empty-art/cuts/{light,dark}/cut-1…6` | Nav, quick-actions, dropdowns, panel headers |
| Seal | `Seal.tsx` | `/empty-art/seal/{light,dark}/seal.png` | Full-panel success moments only |

`ArtKind` = `students | questions | exams | grading | scheduled | classes` —
one motif per product domain, no extras.

---

## 2. The two sign systems (never swapped)

The motifs speak two grammars, both honoring The Mark's "third is gold" law:

- **People speak in the PERSON GLYPH** — figures drawn as line-only glyphs,
  **third head gold** (students, classes).
- **Forms speak in the BUBBLE ROW** — question/exam content drawn as bubble
  rows, **third bubble gold** (questions, exams, grading, scheduled).

A motif never mixes signs. When a new domain needs art, pick the sign by what
the domain *contains* — humans → glyph, documents/flow → bubbles.

The Cuts carry the same gold anchor into chrome, one signature element per
motif (documented in `Cut.tsx`): questions → third answer bubble; students →
third head; exams → the "now" dot at the clock center; grading → the stamp at
the pen tip; scheduled → the marked day tile; classes → the third head in the
pane corner.

---

## 3. Theming = file pick, never runtime recolor

Assets are **pre-rendered keyed RGBA pairs per theme** (light: plum/gold,
dark: cream/gold). Components pick the file by `resolvedTheme`; there is no
CSS filter, no canvas recolor, no runtime tinting. Generated by the
process.py coverage-fit pipeline (spec: `assets/EMPTY-ART-PROMPTS.md`).

Rules:
- New art ships in BOTH theme keys or it doesn't ship.
- `aria-hidden="true"` always — the `EmptyState` title/description carry the
  meaning (same contract for Cuts and Seal: a cut decorates an existing label).
- Static by design — pulse discipline applies to illustrations (no loops,
  nothing for reduced-motion to quiet).

---

## 4. Sizing and placement laws

- **Empty-state art**: 160px at page level, 96px in compact slots
  (`EmptyStateArt` `size` prop). Two slots only — no intermediate sizes.
- **Cuts**: 20 (inline rows) / 24 (headers) / 28 (feature) + 56 (the one
  empty-state host, notifications). Drawn natively at icon composition —
  **never cropped** from the 1254px parent illustration.
- **Seal**: 96px default, full-panel moments only. **Never a toast** — a
  carried rejection: 96px art in a one-line toast. (The ceremony's crest is
  the one authorized reuse at 72px, inside its own stage.)
- **PanelCrest rail** (≥lg): the 136px identity column hosts the motif at
  112px, watermark opacity 60% light / 75% dark when the panel is filled;
  empty→filled swaps only `--crest-op` — zero layout shift is the acceptance
  test. Below lg the rail folds away and centered art stays. Exactly one
  illustration per state (the CSS hides the content column's copy when the
  rail takes over).

---

## 5. Migration and growth rules

- **Cut migration order** (from Art Master Plan C.1/D.3): nav → quick-actions →
  dropdowns → panel headers.
- **lucide stays where no cut exists** (Dashboard home, Plus, Settings, …).
  Never invent a one-off glyph; if a surface needs art, add a proper motif to
  the six-domain set first.
- Adding a new motif = new `ArtKind` + both theme PNGs (illustration + cut) +
  gold-anchor definition + this doc updated. If any of the five is missing,
  the PR is incomplete.
- The seal/absence/hero/neutral families are separate *roles*, not extra
  motifs — they reuse the same drawing language but don't extend `ArtKind`.

---

## 6. A11y & motion contract (summary)

1. Every art `<img>`: `alt=""`, `aria-hidden`, `draggable={false}`.
2. The Seal's entrance is one 240ms sweep (`.seal` / `seal-draw`), then static.
3. `:root[data-motion='reduce']` + media query park the sweep; illustrations
   have no animation to park.
4. Meaning lives in text; art is the room's atmosphere, never the message.
