Liquid Glass Playground

Chromium-only demo

Faithful replica of the kube.io Liquid Glass demo: refraction via SVG displacement map + specular rim, applied with backdrop-filter:url(#lgf). The rim is not a painted color — it is the refracted background itself, saturation-boosted inside the specular ring, with the specular highlight blended on top (article §Combining Refraction and Specular Highlight). Tune the sliders exactly like on the site, then copy the values into the app tokens.

This demo needs SVG filters as backdrop-filter — currently supported only in Chromium. Controls and charts below still work; the glass panel falls back to a plain frosted style.
