راهنمای آزمایش

این صفحه فقط برای بررسی است و به برنامه‌ی اصلی وصل نیست. با «روش رندر» بین دو پیاده‌سازی جابه‌جا شوید:

  • CSS + SVG (فعلی) — همان روشی که الان روی سایت اصلی اجرا می‌شود. در کروم کندی آن را حس می‌کنید، در سافاری خمِ لبه را نمی‌بینید.
  • WebGL2 (جدید) — روش پیشنهادی. باید در هر دو مرورگر روان باشد و خمِ لبه را نشان دهد.
  • هر دو، کنار هم — فقط برای مقایسه‌ی ظاهر؛ عدد روانی در این حالت معنایی ندارد.

برای مقایسه: تعداد پنل را روی ۴۰ بگذارید و صفحه را اسکرول کنید (در کروم حالت CSS باید کند شود، WebGL نه). «آزمون روانی» و «آزمون اسکرول» عدد می‌دهند. سافاری همین حالا هیچ خمِ لبه‌ای ندارد؛ در حالت WebGL باید پیدا شود.
